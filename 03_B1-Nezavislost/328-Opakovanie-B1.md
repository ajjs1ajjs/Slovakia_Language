### 3. GRAMATIKA: veľká tabuľka B1 — 4 javy naraz
| Jav | Vzorec | Príklad |
|---|---|---|
| Kondicionál | l-ové + by | Išiel by som. |
| Imperatív | kmeň + -i/-te | Choď! Choďte! |
| Vedľajšia veta | hlavná + spojka + vedľajšia | Učím sa, aby som vedel. |
| Trpné príčestie | byť + -ný/-tý | Je to napísané. |
Приклади:
1. Keby som mal čas, išiel by som s tebou, aby sme si oddýchli. — (kondicionál + účel)
2. Povedz mi, čo si kúpil, lebo to potrebujem vedieť! — (imperatív + vedľajšia)
3. Úloha je urobená, hoci to trvalo dlho. — (пасив + hoci)

### 6. CVIČENIA
**1. Roztrieď:** (Išiel by som / Choď! / aby som vedel / je napísané) → kondicionál? imperatív? účel? pasív?
**2. Переклади:** a) Якби я знав... b) Скажи мені! c) Номер оплачено.
**3. Mix-veta:** з'єднай в 1 речення: Keby + kondicionál + aby.

**Kľúč / Ключі:**
1. Išiel by som = kondicionál; Choď! = imperatív; aby som vedel = účel; je napísané = pasív (trpné).
2. a) Keby som vedel/a... b) Povedz mi! c) Izba je zaplatená.
3. (зразок) Keby som mal čas, išiel by som von, aby som si oddýchol.
