### 3. GRAMATIKA: negácia **nie / nie je / nemám**
Nie + прикметник/прислівник: nie veľký, nie dnes. Nie je + іменник: Nie je pondelok. Nemám + акузатив: Nemám čas.
| klad | zápor |
|---|---|
| Je pondelok. | Nie je pondelok. |
| Mám čas. | Nemám čas. |
| Je to ďaleko. | Nie je to ďaleko. |
- 3 приклади: Nie je sobota. — Не субота. / Nemám čas dnes. — Не маю часу сьогодні. / Nie, nie je večer. — Ні, не вечір.

### 4. DIALÓG: Koľko je hodín?
1. — Prosím, koľko je hodín? [ˈkɔʎkɔ jɛ ˈɦɔɟiːn] — Скажіть, котра година?
2. — Je pol tretej. [jɛ pɔl ˈtracɛj] — Пів на третю (друга тридцять).
3. — Ďakujem. Kedy máme stretnutie? [ˈkɛdi ˈmaːmɛ ˈstrɛtnucɪɛ] — Дякую. Коли в нас зустріч?
4. — Zajtra o desiatej. [ˈzajtra ɔ ˈɟɛsjatej] — Завтра о десятій.
5. — V piatok nie? [f ˈpiatɔk nɪɛ] — У п'ятницю ні?
6. — Nie, v piatok nemám čas. [nɪɛ f ˈpiatɔk ˈnɛmaːm t͡ʃas] — Ні, у п'ятницю не маю часу.
7. — Dobre, zajtra o desiatej! [ˈdɔbrɛ] — Добре, завтра о десятій!

### 5. VÝSLOVNOSŤ
- `ď [ɟ]`: pondelok, hodina — м'яке «дь», не «д».
- `ie`: nie [ɲɪɛ] — «ньіе» одним складом.
- Довгі: minúta, nedeľa — тягни «уу», «є».
